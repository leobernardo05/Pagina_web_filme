# 🎬 Página Web — Filme Velozes e Furiosos 7

Projeto de página web desenvolvido com foco em interface moderna, responsiva e interativa, apresentando informações sobre o filme **Velozes e Furiosos 7**.  
O objetivo deste projeto é praticar desenvolvimento front-end utilizando tecnologias atuais e boas práticas de organização de código.

---

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- React
- Vite

---

## 🎯 Funcionalidades
- Interface moderna e responsiva
- Layout adaptado para diferentes telas
- Componentização com React
- Carregamento rápido com Vite
- Estrutura organizada e escalável
